browser native test page

This page is served by kj-httpd and exercises a pile of native html and css features. If everything below responds to you, the whole file made it across the wire intact. Flip, click and drag around.

tabs

A tab set built from radio buttons and sibling selectors.

Static serving. Files come off the disk, mime types are picked by suffix, and single byte ranges work if you ask for one. Gzip passthrough kicks in when a pre-compressed neighbor exists.

Headers. Responses carry a date, an etag, a last modified stamp and a content length. Conditional requests with that etag answer 304 without touching the file again.

Files. This very page, plus index.html, a license and a readme. The server is a 37 kilobyte static binary with no runtime dependencies, so the serving story is short: one file, one process per request.

collapsible panels

Native disclosure widgets, open and close to your heart's content.

What is this page for?

It is a smoke test with style. Request it after starting the server and everything here should be clickable, hoverable and scrollable. It is also a handy mirror to hold up to a browser.

Where do the widgets get their behavior?

Checkbox and radio inputs, sibling and :has() selectors, counters and one details block. Standard browser fare.

Can I share a link to a tab?

No deep links into widget state for now, the section anchors in the nav do work though.
